# Агерис — пест-менеджмент по ХАССП (агерис.рф/audit), версия 2

Статическая версия посадочной страницы агерис.рф/audit с исправлениями по отчёту PageSpeed Insights от 27.10.2026.
Контент и дизайн взяты из предпросмотра [ageris-audit](https://github.com/sokolnikovalex1975/ageris-audit) (он не изменялся).

Предпросмотр: https://sokolnikovalex1975.github.io/ageris-audit-v2/

## Что исправлено

| Замечание PageSpeed на агерис.рф/audit | Что сделано |
|---|---|
| Синхронный скрипт Botfaqtor (3 с блокировки) и jQuery в `<head>` | jQuery, Swiper и Fancybox не используются. Метрика, UIS (CoMagic), Botfaqtor и Radist подключаются из `main.js` после отрисовки: при первом действии посетителя или через ~1,5 с после загрузки страницы |
| Google Fonts: блокирующий CSS и 265 КБ шрифтов | Свои файлы WOFF2 с кириллицей: Montserrat 39 КБ, Literata 40 КБ, `font-display: swap`, preload, метрики резервных шрифтов подогнаны, чтобы текст не «прыгал» |
| Блокирующий файл стилей | CSS встроен в страницу (28 КБ, около 6 КБ в сжатом виде) |
| Главное фото 2,15 МБ JPG с `loading="lazy"` | AVIF/WebP 10–74 КБ с `srcset`, preload и `fetchpriority="high"`, без отложенной загрузки; для телефонов отдельный кадр с людьми и планшетом |
| Вес страницы 7,9–10,1 МБ | Первый экран: 137 КБ на телефоне и 152 КБ на компьютере; вся страница после прокрутки 275–459 КБ |
| Картинки без размеров и современных форматов | Все фото в AVIF с WebP-запасом, `width`/`height`, адаптивные `sizes`, `loading="lazy"` ниже первого экрана |
| Нет meta description, двойной title | Один `<title>`, description, canonical, Open Graph, разметка Schema.org (Organization, Service, FAQPage, BreadcrumbList) |
| Контраст, иконки-ссылки без подписи | Контраст по WCAG AA, у ссылок Max и Telegram есть `aria-label` |
| Нет favicon (ошибка 404 в консоли) | `img/favicon.svg` |
| Принудительная перекомпоновка в скрипте | Тень шапки и анимации появления работают через IntersectionObserver, без чтения размеров при загрузке |

Дополнительно:
- в блоке «Как формируется стоимость» появилась иконка «Документация и отчётность» (в прежней версии её не было);
- исправлена маска телефона: `8 916 123-45-67`, `+7 916…`, `7916…` и вставка номера дают `+7 (916) 123-45-67`, городские номера на 8 (например, 812) не обрезаются;
- ссылки Max и Telegram такие же, как на агерис.рф, без зашитого кода сессии; номер заявки в них подставляет Radist.

## Как работает предпросмотр

- Режим определяется по адресу. На github.io и локально форма проверяет поля, но заявку не отправляет и показывает сообщение «Режим предпросмотра»; сторонние счётчики не грузятся.
- На агерис.рф (`агерис.рф` или `xn--80aggm3bh.xn--p1ai`) форма отправляет данные в Contact Form 7, форма №148: `POST /wp-json/contact-form-7/v1/contact-forms/148/feedback`, поля `text-1` (имя), `tel-1`, `text-2` (компания), `text-3` (отрасль), `textarea-1` (комментарий; для кнопок с темой в начало добавляется «Тема: …»).
- После успешной отправки: цель Метрики `audit` (счётчик 24148573) и `Comagic.addOfflineRequest({name, phone})`, как на текущей странице. Клики по телефону, Max, Telegram и кнопкам заявки отправляют цели `click_phone`, `click_max`, `click_telegram`, `open_form_*`.

## Перенос на агерис.рф

1. Положить `img/`, `fonts/` и `main.js` в тему, например `/wp-content/themes/ageris/audit/`, и поправить относительные пути в разметке (`img/…`, `fonts/…`, `main.js`) на адреса темы.
2. В шаблоне `page-audit.php` вывести разметку из `index.html`: блок `<head>` (meta, preload, `<style>`) и содержимое `<body>`.
3. Для этого шаблона отключить jQuery, Swiper, Fancybox, стили и скрипты CF7, а также вставки Метрики, UIS, Botfaqtor и Radist в шапке и подвале: их подключает `main.js`. Иначе визиты и заявки будут считаться дважды.
4. Заменить `og:image` на адрес картинки на агерис.рф.
5. Добавить заголовки безопасности на сервере (nginx или `send_headers` в WordPress): `Strict-Transport-Security`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `X-Frame-Options: SAMEORIGIN` или CSP `frame-ancestors`.
6. После переноса проверить отправку тестовой заявки, достижение цели `audit` в Метрике и подмену номера UIS, затем заново прогнать PageSpeed.
